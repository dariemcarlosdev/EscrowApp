description: Create a specification before coding — define requirements, acceptance criteria, and boundaries
---

Invoke the spec-writer skill. Read and follow:

```
cat .github/skills/project-management/spec-writer/SKILL.md
```

Before writing any code:

1. Surface your assumptions explicitly — list what you're assuming about scope, architecture, and behavior
2. Ask clarifying questions for anything ambiguous
3. Write a structured spec covering: Objective, Tech Stack, Code Style, Testing Strategy, Boundaries, Success Criteria
4. Get human review before proceeding to implementation
5. Save the spec to a file in the repository

If the idea is vague, start with the idea-refine skill first:
```
cat .github/skills/project-management/idea-refine/SKILL.md
```
